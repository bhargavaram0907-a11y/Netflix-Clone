# Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS.

## 📌 About the Project

This project recreates the Netflix landing page interface as a frontend development practice project.

It focuses on creating a responsive layout, reproducing the visual structure of a streaming platform, and working with HTML, CSS, images, and video assets.

## 🚀 Features

- Netflix-inspired landing page
- Responsive layout
- Navigation bar with language and sign-in buttons
- Hero section with email input
- Content sections for TV, mobile, and other devices
- FAQ section
- Footer with navigation links
- Background image and video assets
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts
- HTML5 Video
